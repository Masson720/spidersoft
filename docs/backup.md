# Backup system

## Script

Location:

/opt/spidersoft/scripts/backup.sh


## Usage

Default backup:

./backup.sh


Custom directory:

./backup.sh /etc


## Storage

Backups are stored in:

/opt/spidersoft/backups


## Logging

Backup events are written to:

/var/log/spidersoft/admin.log


## Example

Successful backup:

2026-07-09 17:30:00 [INFO] Backup created: app-2026-07-09_17-30-00.tar.gz
